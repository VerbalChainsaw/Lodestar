# Multi-Perspective Cascade

A cascade is a set of independent CENTER audits over one broad surface, followed by evidence synthesis. It is useful only when that surface contains materially different causal contracts that one center cannot represent cleanly.

## Applicability

Use a cascade when distinct layers or evidence channels can fail independently and the current question genuinely spans them, or when the user explicitly requests several independent perspectives. Do not use it for one localized defect, a routine yes/no, or to create confidence by volume.

## Lens design

Choose only evidence-bearing lenses. Each lens owns a different material invariant or causal boundary, uses a distinct primary evidence surface when possible, states what it does not inspect, receives the same raw observation and target revision, and remains blind to the lead auditor's evolving verdict.

There is no lens quota. Add a lens while it can resolve an uncovered material boundary, contradiction, or independent-evidence need. Stop when the evidence converges or another lens cannot change the conclusion.

## Dispatch

Use the independent-worker mechanism available in the current environment. Prompt and transport shapes differ across hosts, so adapt transport without changing the audit meaning. Do not turn one host's payload format, timeout, or path convention into universal skill policy.

## Incomplete results

Worker output is untrusted until load-bearing claims are verified. Determine completeness from required evidence and structure rather than file size. A timeout, malformed response, missing artifact, or truncated report is a transport/execution failure, not proof that the audited surface is clean or broken.

Recover only missing material evidence. If another independent lens already establishes the same invariant, note the failed lens and continue. If missing evidence can change the verdict and cannot be recovered, report the gap and calibrate confidence or return `INCONCLUSIVE`.

## Synthesis

For every confirmed or disproven claim, record which lenses support it and which evidence IDs are genuinely independent. Merge convergent findings that describe the same mechanism. Keep unique findings clearly single-source. Surface disagreements without voting or averaging.

Prioritization for repair follows user scope, severity, evidence quality, blast radius, reversibility, and leverage. The cascade itself does not authorize automatic repair, fixed batching, commits, or another audit cycle.
