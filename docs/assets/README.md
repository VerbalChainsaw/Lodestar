# Lodestar brand assets

## Product mark

`lodestar-mark.png` is the primary standalone Lodestar emblem. It combines a
fixed eight-point navigation star with four linked context nodes. The PNG uses
an alpha channel and is suitable for repository, installer, application, and
social-profile use.

- Canvas: 1254 × 1254
- Format: RGBA PNG
- Background: transparent

## Hero illustration

`lodestar-hero.png` is the panoramic repository hero. Its central fixed star
routes a network of project structures and represents Lodestar's role as a
deterministic context plane.

- Canvas: 2172 × 724
- Format: RGB PNG
- Intended ratio: 3:1

Both assets are part of the Lodestar repository and are distributed under the
repository's MIT License.
