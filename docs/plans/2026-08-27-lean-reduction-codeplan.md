# Lodestar lean reduction codeplan

Date: 2026-08-27
Scope owner: Director
Method: Codeplan (evidence-gated) + Center Audit (claim proof) applied before each edit.
Status: EXEC-OUT (implemented, validated: 166/166 tests, pack check, packed-artifact smoke).

## Task contract

- Required behavior: remove overbuilt subsystems identified by the 2026-08-27
  overbuild audit where evidence proves they are dead weight; keep every wired,
  purposeful capability; keep all remaining tests green and the release
  metadata contract valid.
- Acceptance criteria: full suite passes; `pack:check` passes; packed-artifact
  smoke passes; no dangling references to removed subsystems; README, skill
  references, CHANGELOG, and package surface updated; v1.5.0 tag/release state
  untouched; `.backups/` untouched.
- Must preserve: the JSON envelope, DB schema v4 (no data migration in this
  tranche), record states as stored, the Codex plugin MCP tool surface, the
  agent-agnostic package payload (skills for all agents), the golden-rules
  governance record.
- Out of scope: self-register enablement design (future), npm publish/push
  (awaits authorization), `.backups/` cleanup, state-ontology migration.

## Repository evidence (calibrated)

- `src/import-v070.mjs` + `src/legacy-v070/*` (~2,115 lines, 25% of src) are
  referenced only by the `import` command branch in `src/agent-state.mjs:236`
  (dynamic import) and by tests (`import-v070.test.mjs`, `legacy-v070.test.mjs`,
  `unified-migration.test.mjs`, `concurrency.test.mjs`). No start/handoff/
  doctor/put/get path consumes them. The v0.7 migration is long complete (DB is
  schema v4, healthy).
- `work` presence is NOT dead: `codex-plugin/scripts/lodestar-mcp.mjs` and
  `lodestar-runtime.mjs` expose work tools; `README.md:81-93` documents
  advisory presence and actor-keyed identity; `test/work-identity.test.mjs`
  exists. Cutting it breaks the plugin contract.
- `content.state` is required and schema-enforced
  (`src/validate.mjs:142-146`, `schema.mjs` CHECK `IN ('known','known_empty',
  'unavailable','unknown','stale')`). Collapsing states is a v4→v5 schema
  migration with data remap; deferred.
- `managed-assets/manifest.json` lists the six-skill payload; `skills verify`
  compares installed copies against it. This payload is the cross-agent
  distribution surface (Director goal: packages for every agent); removing the
  five governance skills would strand Claude/Codex/OpenCode copies without a
  canonical source.
- The codex-plugin lodestar mirror is generated by
  `scripts/build-managed-assets.mjs` with parity checks — single source of
  truth plus drift protection, not hand-maintained duplication.
- `release.yml` publishes only when `docs/assets/lodestar-launch-hero.png`
  exists (`release_hero=...`), enforced by `test/release.test.mjs:97`. A
  marketing image is a CI gate — theater.

## Candidates

- V1 `evidence-gated sweep` (fingerprint: `surgical-deletion`,
  `contract-preserving`, `no-schema-change`): cut the v0.7 importer and the
  release hero gate; reject/defer the remaining audit items with the evidence
  above; keep work presence, states, markers, mirrors, decision authority, and
  the six-skill payload.
- V2 `full audit sweep` (fingerprint: `broad-removal`, `schema-migration`,
  `plugin-contract-change`): implement every audit recommendation, including
  removing work presence, migrating states to three, stripping the payload to
  one skill, and removing the marker grammar.
- V3 `minimal importer-only` (fingerprint: `smallest-cut`): remove only the
  v0.7 importer; leave the hero gate and everything else.

## Paper gates (before scoring)

- V1: task-fulfillment pass — removes the dead weight; contract-preservation
  pass — no wired surface touched; negative-space pass — removes subsystems

  requires a schema migration (states), and removes the cross-agent payload

  from scoring.
- V3: pass all gates, but leaves the hero-gate theater in place.
