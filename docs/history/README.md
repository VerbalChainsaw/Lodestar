# Historical documentation

This directory preserves migration evidence and retired implementation records. It is history, not current operating guidance.

Use the [current documentation index](../README.md), [installation guide](../installation.md), [schema and contract](../schema.md), [limitations](../limitations.md), and [2.1.2 release notes](../releases/v2.1.2.md) for the supported product.

Past release notes under `docs/releases/`, announcements under `docs/announcements/`, and plans under `docs/plans/` retain their original chronology. Commands, architecture, versions, paths, test counts, and pending work in those files describe the named historical point and may no longer be valid.

The files in this directory are retained for provenance:

- `2026-08-19-golden-rules-migration.md` records a retired 1.x governance migration.
- `retired-policy-compiler-transformations.json` preserves machine-readable transformation evidence from that retired design.
