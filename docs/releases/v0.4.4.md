# Lodestar v0.4.4

Lodestar v0.4.4 makes the public MIT-licensed package the single canonical
implementation for native Windows, WSL, Linux, and macOS. It retains the
private-engine capabilities while hardening installation, recovery, writes,
discovery, diagnostics, and the agent lookup contract.

## Highlights

- Exact `get` and bounded `resolve` now precede scoped `find` in the installed
  Codex contract, so agents follow linked context before searching.
- `put` uses the same audited transaction and rollback boundary as other writes,
  preserves locator health, and protects generated records from accidental
  curated overwrite.
- `doctor` fails closed when required state cannot be read and provides explicit
  current-pointer and stale-lock repair commands.
- Legacy/private flat stores migrate into the public generation format without
  modifying the source store or losing curated records.
- Windows and WSL roots are deduplicated by physical identity, while discovery
  candidates are revalidated inside the writer lock.
- The installer validates package identity, suppresses package lifecycle
  scripts, uses the validated Node executable in Windows shims, and restores the
  prior package if post-install setup fails.
- Guided initialization and the deterministic 100-project material-lift fixture
  verify useful startup context, bounded transfer, and exact retrieval at scale.
- CI now derives the package artifact name from `package.json`, preventing a
  release version from testing an older tarball by mistake.

## Install

Download `lodestar-agent-context-0.4.4.tgz` and `SHA256SUMS.txt` from this
release, verify the checksum, and install:

```powershell
# Native Windows PowerShell
npm install --global .\lodestar-agent-context-0.4.4.tgz
agentctx init
agentctx doctor
```

```sh
# WSL, Linux, or macOS
npm install --global ./lodestar-agent-context-0.4.4.tgz
agentctx init
agentctx doctor
```

For a shared Windows/WSL state store, use the same Windows directory from each
runtime:

```powershell
agentctx init --home C:\Users\name\.lodestar
agentctx install-codex --home C:\Users\name\.lodestar
```

```sh
export LODESTAR_HOME=/mnt/c/Users/name/.lodestar
agentctx doctor
```

## Upgrade from the legacy/private implementation

The public package is the implementation. The legacy directory is only a
migration source and should not remain on `PATH`:

```powershell
agentctx migrate-legacy `
  --from C:\Users\name\.agent-context `
  --home C:\Users\name\.lodestar
agentctx doctor --home C:\Users\name\.lodestar
```

Migration is non-destructive. Keep the legacy directory as a backup until the
new store passes `doctor`, then run only the public `agentctx` installation.
