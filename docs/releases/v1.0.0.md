# Lodestar 1.0.0

Lodestar 1.0 is a deliberate architectural reset: a small, offline,
JSON-first context registry backed by one local SQLite database.

## What ships

- one executable: `lodestar`;
- nine commands for initialization, records, bounded search, explicit links,
  diagnostics, export, deletion, and one-way v0.7 import;
- exact IDs and aliases, five honest knowledge states, and explicit source
  observations;
- atomic SQLite transactions, read-only query connections, bounded machine
  inputs and outputs, and stable JSON errors;
- zero runtime dependencies, background processes, network requirements,
  plugins, providers, or installers.

Install globally with Node.js 24.15.0 or newer:

```text
npm install --global lodestar-agent-context@1.0.0
lodestar init
```

## Migration

Version 1.0 does not run the v0.7 generation store and does not dual-write.
Preview the one-way conversion first:

```text
lodestar import /path/to/v0.7/store --dry-run --db /path/to/lodestar.db
```

Review every skipped, unsupported, remapped, emitted, and omitted report count
before committing the import or discarding the old store. The importer never
mutates the source.

See the packaged migration and limitations documents for the complete
contracts.

## Deliberate removals

The release removes generation trees, commit pointers, heartbeat locks,
snapshots, quarantine, readiness scoring, repository discovery, provider
experiments, installer rollback, benchmark commands, orchestration behavior,
and ten former executables. Historical v0.x documentation and artifacts remain
available from their tags and GitHub releases.

## Verification

The release candidate closed 40 independently reproduced audit findings. The
final suite contains 80 tests and exercises the packed executable, all commands
and help paths, read-only byte stability, concurrent database reservations,
stored-data corruption, migration loss accounting, and a genuine sealed v0.7
store. The tag workflow repeats tests, package installation, and CodeQL on
hosted Linux, macOS, and Windows before publication.

Lodestar does not claim complete project understanding, universal accuracy,
readiness, or automatic token improvement. Missing records remain missing
knowledge, and callers fall back to normal repository inspection.
