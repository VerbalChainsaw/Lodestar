# Lodestar 1.0.3

Lodestar 1.0.3 puts the most important conclusion from the 1.0 rewrite on the
front page: for the job Lodestar now claims, the reduced version is the better
product.

The original Lodestar proved the value of stable, structured project context.
It also accumulated custom storage generations, lifecycle machinery,
installers, readiness claims, provider experiments, and multiple executables.
Those systems made sense while the product was still exploring its shape, but
they are not needed for a small local context registry.

Lodestar 1.0 keeps the useful qualities—deterministic JSON, explicit schemas,
stable IDs, bounded behavior, careful paths, cross-platform support,
actionable diagnostics, atomic transactions, and honest uncertainty—and
rebuilds the product around one SQLite database and one CLI.

I believe that makes this Lodestar easier to understand, safer to operate, and
more durable. It is the version I recommend.

![Lodestar launch hero](https://raw.githubusercontent.com/VerbalChainsaw/Lodestar/v1.0.3/docs/assets/lodestar-launch-hero.png)

## What changed

- The GitHub and npm front page now includes a direct original-versus-1.0
  comparison near the top.
- The comparison explains what was retained, what ceased to exist, and why the
  reduction improves the current product rather than merely shrinking it.
- A version-specific social card is attached to this release.

No command, schema, database behavior, migration behavior, dependency,
package-content boundary, or executable changed from 1.0.2.

## Install

Node.js 24.15.0 or newer is required:

```text
npm install --global lodestar-agent-context@1.0.3
```

No setup command is required. The first structurally valid `lodestar put`
creates the registry automatically.

## Release verification

The tag workflow must pass the complete test suite, package-content checks,
packed-executable smoke tests on Linux, macOS, and Windows, and CodeQL before
publishing. It then publishes the exact tarball to npm with provenance,
attests the same artifact on GitHub, and attaches checksums and launch graphics
to this release.
