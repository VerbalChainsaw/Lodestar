# Lodestar v0.4.3

Lodestar is a local, deterministic linked-context store and project discovery
tool for coding agents. It gives an agent one small startup packet, stable links
to exact operational knowledge, and scoped search before repository-wide
inspection becomes necessary.

## Highlights

- Native Windows, WSL, Linux, and macOS support on Node.js 22 or newer.
- A shared Windows/WSL state store when both sides are configured to use the
  same Windows directory.
- Stable record IDs, bounded graph traversal, deterministic scoped search, and
  immutable transactional store generations.
- Safe migration from legacy/private flat stores without mutating the source.
- Project discovery, profiling, refresh, doctor, coverage, Codex installation,
  and manifest-backed rollback.
- MIT licensing and complete public installation and operating documentation.
- Correct stale-lock recovery guidance; the CLI no longer recommends a
  nonexistent repair command.

## Install

Download `lodestar-agent-context-0.4.3.tgz` and verify it against
`SHA256SUMS.txt`, then run:

```sh
npm install --global ./lodestar-agent-context-0.4.3.tgz
agentctx init
agentctx doctor
```

For a guided installation from a checkout or downloaded source archive:

```powershell
# Native Windows PowerShell
.\install.ps1
```

```sh
# WSL, Linux, or macOS
./install.sh
```

The installer can migrate an existing store with
`--legacy-home <legacy-store>` and can leave Codex configuration untouched with
`--skip-codex`.

## Upgrade

Reinstall the release tarball over the existing npm prefix. Lodestar state lives
outside the package, so package replacement does not replace the context store.
Run `agentctx doctor` after upgrading. Keep a backup of irreplaceable data even
though Lodestar writes store generations transactionally.

## Verification

This release is gated by the Node test suite, dry-run and real package
installation checks, package-content validation, and GitHub Actions on Windows,
Ubuntu, and macOS. The release workflow publishes the exact tested npm tarball
and its SHA-256 checksum.

See the
[README](https://github.com/VerbalChainsaw/Lodestar#readme)
