# Lodestar 1.4.3

Package: `lodestar-agent-context@1.4.3`.

Lodestar's Codex hook executable now accepts a UTF-8 byte-order mark before its complete
JSON input. Some Windows command pipelines preserve that marker; passing it directly to
`JSON.parse` failed before Lodestar could distinguish `UserPromptSubmit` from `Stop`.

The adapter removes only the encoding marker at the transport boundary. It does not cap,
truncate, omit, or partially parse the hook payload.

Regression coverage now spawns the real hook executable and sends BOM-prefixed prompt and
stop events through stdin, verifying exit status and complete JSON output.

Requires Node.js 24.15.0 or newer.
