# Lodestar 2.0.2

Package: `lodestar-agent-context@2.0.2`.

Closes upgrade recovery and launcher omissions in 2.0.1. The database schema and
model-facing contract remain at 5.

- Recovery binds staging and backup paths to one operation, validates complete
  inventories, and checks preserved bytes before restoring or removing anything.
  Unexpected or partial staged contents are retained and reported while retrying.
- Lock ownership lives in a complete filename rather than a partially writable JSON
  body. An abruptly exited local installer can be reclaimed on retry.
- Journal and receipt files, staged payloads, and launcher recovery copies are
  flushed before publication. Changed destinations or backups are preserved.
- Launcher receipts support ordinary owned upgrades. Local edits still require
  explicit review; destinations inside skills or recovery metadata are rejected.
- An explicit WSL `--home` isolates inherited host homes. Explicit per-host options
  continue to win, including Hermes home selection.

Regression checks include actual child process exit during displacement, malformed
recovery metadata, concurrent edits, launcher ownership, and WSL argument transport.
Process interruption testing does not establish physical power-loss durability or
atomic replacement across all hosts. See [installation](../installation.md) and
[limitations](../limitations.md).

Install the supplied local tarball, then repeat the selected `setup --apply`
command. The first launcher migration from a release without launcher receipts may
require reviewed `--replace-local`; subsequent unmodified owned upgrades do not.
Start fresh agent sessions to load the installed instructions.
