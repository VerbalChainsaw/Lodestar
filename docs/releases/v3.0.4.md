# Lodestar 3.0.4

Candidate date: 2026-11-27.

Lodestar 3.0.4 pairs with native Codex adapter 1.4.9, unchanged from 3.0.3.

## Windows application upgrade

An owned upgrade can preserve its selected current-schema database even when historical receipts are offline. It still runs the full database diagnostic and rejects any other issue. The installer prints the deferred-history count and records it in the installation receipt. No migration, archive restore, receipt deletion or history replay occurs. First installation and migration keep their existing validation. Full doctor remains incomplete until the archive is available.

Download verified matching artifacts from the [GitHub release list](https://github.com/VerbalChainsaw/Lodestar/releases). See the [installation guide](../installation.md).

## Local candidate installation

If this version has not been published to npm or GitHub, use the verified local candidate artifacts. The Windows package is Lodestar-3.0.4-win-x64.zip.
It requires Node.js 24.15.0 or newer, .NET 10 Desktop Runtime (x64), and PowerShell 7.
The [3.0.0 release](https://github.com/VerbalChainsaw/Lodestar/releases/tag/v3.0.0) remains available as a historical download.

```powershell
npm install --global --ignore-scripts "<candidate-directory>/lodestar-agent-context-3.0.4.tgz"
```
