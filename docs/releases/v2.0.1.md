Package: `lodestar-agent-context@2.0.1`.

Repairs installation and startup routing without changing contract 5 or the database schema.

- Ships explicit `setup` planning/application with owned payload receipts, retained
  backups, physical path deduplication, and interrupted tree recovery.
- Uses the same discovery resolver for installation and read-only skill verification.
  Reports OpenCode alternate roots and separates identical mirrors from conflicts.
- Fixes WSL path transport and home selection across global option placement and
  different launch directories; retains the Windows-owned SQLite boundary.
- Protects changed launchers and makes their replacement retryable.
- Replaces the obsolete WSL acceptance script with current-contract checks.

Follow [installation and startup checks](../installation.md). Native host configuration
and already-loaded instruction text are separate from payload bytes: inspect actual
host discovery and restart sessions after upgrading. No automatic instruction rewrite,
host hooks, daemon, or session creation is introduced.
