Candidate date: 2026-10-29.

**Local candidate.** Version 3.0.2 has not been published to npm or GitHub.
The [published 3.0.0 release](https://github.com/VerbalChainsaw/Lodestar/releases/tag/v3.0.0)
remains the retained public release. Pushing this source branch is not publication of a package or release.

## Changes and limits

- Schema 6 stores losslessly compressed mutation receipts and explicit cold-history references. Existing schema 5 remains readable and writable; explicit schema 4 migration still targets schema 5. No automatic database migration, archive restore or history deletion occurs.
- Full doctor output is bounded with exact finding counts and explicit omissions. Cold history remains `complete: false`, `healthy: null`; quick checks are not whole-database certification. Exhaustive validation work remains proportional to data.
- Verified restore caches reject changed file generations. Explicit budgeted `--verify-existing` repairs interrupted verification receipts; normal reads never silently restore a large archive. Ordinary file-change detection is not tamper protection: same-user code can alter cache rows and restore timestamps without privilege. Archive-pointer reads trust that local cache; explicit budgeted `--verify-existing` detects changed bytes with the full checksum. No per-read cryptographic integrity guarantee is claimed.
- Compatibility checks cover compressed and legacy receipts, Windows and POSIX paths, installer schema selection, and retained migration/recovery contracts.

Keep compressed recovery archives and the original rollback files until separate approved retirement. See [lean storage](../lean-storage.md) for restore limits; this candidate does not authorize cleanup.

## Local installation

Use Node.js 24.15.0, .NET 10 Desktop Runtime (x64), and PowerShell 7 for the Windows suite. Verify the locally built package against its matching SHA-256 inventory before installation:

```powershell
npm install --global --ignore-scripts "<candidate-directory>/lodestar-agent-context-3.0.2.tgz"
```

Do not infer that a running consumer has loaded source changes from a source commit alone. Preserve current service and database ownership during supported activation.
