# Lodestar 2.2.1

Package: `lodestar-agent-context@2.2.1`.

A focused follow-up to 2.2.0, from a second adversarial review pass over the
rejection register and the agent-facing surface. Contract 5 and schema 5 are
unchanged; existing stores need no migration.

## What changed

- **Rejections follow project rebinding.** The write-time advisory now also
  matches rejections recorded under a project's historical member scopes, so a
  rebinding project keeps intercepting subjects it already settled.
- **Limited reads say what they omit.** `work` and `pending` reads that hit
  `--limit` now set the envelope `more` flag; full lists report `more: false`.
- **Help declares the real shapes.** JSON help now documents the nested input
  shapes (handoff checkpoint fields, promotion destination `put` vs
  `decision.set` variants, decision direction), the global options
  (`--db`, `--output`, `--args-file`, `--args-stdin`, `--human`), and states
  that `--limit`/`--at-revision` apply to reads while mutations are guarded by
  the request write basis.
- **Discovery failures are reported.** A failed Git discovery execution now
  raises a typed `project_discovery_failed` instead of silently deriving a
  working-directory identity.
- **Verification invariants documented.** AGENTS.md now records the managed
  byte-manifest rule and the required `--source-root` regeneration invocation.

## Upgrade

```text
npm install --global lodestar-agent-context@2.2.1
lodestar setup --target all
lodestar setup --target all --apply
```

## Compatibility

Requires Node.js 24.15.0 or newer. Contract 5 and schema 5 are unchanged; no
new migration is required. Release checks run on Windows, Linux, and macOS.
