# Lodestar 3.0.3

Candidate date: 2026-11-27.

Lodestar 3.0.3 and native Codex adapter 1.4.9 are the supported release pair.

## What changed

- Startup gives a short routing hint, not a project dump. Ordinary prompts and completed replies no longer append transcript tails. Update an existing project record once when a material decision, milestone, blocker, handoff, or completion changes what the next person needs.
- An explicitly bound PreCompact event checkpoints a changed work projection only. If the normal compact-start recovery callback is missed, the next prompt in that exact session can attempt one bounded readback. A synthetic callback or visible hook is not proof that Codex acted on the advice.
- One native MCP server exposes checked core reads and writes alongside the host-attested work and handoff tools. The core contract and session checks are unchanged.
- The repository includes an offline storage-footprint observer and one-shot chat-evidence review tooling. Neither runs on startup, changes a live store, starts a background process, or automatically ingests transcripts.

## Install and verify

Download the paired assets and checksum inventory from the [GitHub release list](https://github.com/VerbalChainsaw/Lodestar/releases).
Use the [installation guide](../installation.md) for Loader, Manager, CLI and the separate [native Codex adapter](../../native-codex/README.md).
Keep one active native adapter per Codex host, retain rollback, and verify the actual selected core at all entry points.
Existing schema 5 and 6 stores remain supported; installation does not authorize an automatic database migration, cleanup, or transcript enrollment.

## Local candidate installation

If this version has not been published to npm or GitHub, use the verified local candidate artifacts. The [3.0.0 release](https://github.com/VerbalChainsaw/Lodestar/releases/tag/v3.0.0) remains available as a historical download.

The Windows suite needs Node.js 24.15.0 or newer, .NET 10 Desktop Runtime (x64), and PowerShell 7. Verify the exact local package hash, then install with:

```powershell
npm install --global --ignore-scripts "<candidate-directory>/lodestar-agent-context-3.0.3.tgz"
```
