# Lodestar 1.0.1

Lodestar 1.0.1 removes the mandatory first-run setup step.

## Changed

- The first structurally valid `lodestar put` initializes an absent default or
  explicit database automatically.
- Concurrent first writers reuse Lodestar's existing exclusive reservation,
  bounded busy window, and SQLite transaction behavior; every valid record
  survives.
- Invalid first writes and every read-only command remain side-effect free.
- `lodestar init` remains available but is optional.
- Hosted package smoke tests begin with `put`, proving zero-touch startup on
  Linux, macOS, and Windows.

No dependency, executable, schema, storage-engine, or migration behavior was
added.

## Install

```text
npm install --global lodestar-agent-context@1.0.1
```

An agent can query Lodestar immediately. The first record it writes creates the
registry; missing records still mean missing knowledge, not completeness.
