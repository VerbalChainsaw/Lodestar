# Lodestar 1.4.2

The workshop rules are global again.

![Lodestar 1.4.2](https://raw.githubusercontent.com/VerbalChainsaw/Lodestar/main/docs/assets/lodestar-v1.4.2-social.png)

```text
npm install --global lodestar-agent-context@1.4.2
lodestar skills sync --target all
lodestar skills verify --target all
```

## Golden Rules are required startup context

The package-owned `g:lodestar:required-governance` record now carries the
universal operating covenant on every `lodestar start`:

- default to a single-operator prototype and development workstation unless a
  current instruction or project contract says otherwise;
- treat dirty, staged, untracked, partial, and committed-in-progress files as
  valid owner-authorized work;
- build on existing work and fold relevant partial work forward;
- never quarantine, bypass, ignore, overwrite, reformat, or rebuild around WIP;
- never roll back, reset, clean, stash, restore, or checkout over work without
  explicit permission;
- protect work first, honor exact scope, produce the result, verify the claim,
  report honestly, leave optional improvements alone, and stop;
- read surgically, distinguish unknown from absent, preserve existing
  architecture and data contracts, and reject speculative parallel systems.

## One always-on owner

`director-protocol` remains available for Director-specific scope,
coordination, and reporting behavior. It now points to required startup
governance for universal worktree rules instead of carrying a second copy.

## Semantic lock

New regression tests require the canonical governance source, generated payload,
and live startup projection to match exactly. They also exercise startup at the
minimum supported 8 KiB budget and fail if the Golden Rules are demoted,
truncated, or omitted.

## Upgrading

There is no schema migration. Install the package, then sync and verify managed
skills so configured clients receive the updated optional skill package.

```text
npm install --global lodestar-agent-context@1.4.2
lodestar skills sync --target all
lodestar skills verify --target all
```

Requires Node.js 24.15.0 or newer.
