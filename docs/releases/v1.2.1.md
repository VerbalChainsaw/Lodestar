# Lodestar 1.2.1

A packaging correction on top of [1.2.0](v1.2.0.md). No runtime behavior changes.

1.2.0 removed three project-specific instruction templates from the published
package, but left the reference table that listed them. The shipped table named
private projects and pointed at files the artifact no longer contains.

![Lodestar 1.2.1](https://raw.githubusercontent.com/VerbalChainsaw/Lodestar/v1.2.1/docs/assets/lodestar-v1.2.1-social.png)

## Fixed

- Removed the three stale rows from the packaged template reference.
- Added a release check that fails when packaged documentation cites a template
  absent from the built artifact. The existing relative-link check did not catch
  this because the table cites templates as inline code rather than as links.

## Install

Node.js 24.15.0 or newer is required:

```text
npm install --global lodestar-agent-context@1.2.1
lodestar start --cwd .
```

## Upgrading

Nothing to do beyond installing. The schema, CLI surface, and registry format are
identical to 1.2.0.
