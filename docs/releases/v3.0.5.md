# Lodestar 3.0.5

Core 3.0.5 pairs with the separate native Codex adapter 1.4.10.

- Manager prepares and flushes both files before publishing a recovery entry. Interrupted preparation remains inspectable but is not replayable.
- The installer uses one read snapshot. Only missing or stale offline archive dependencies qualify for the existing same-store exception; malformed or mismatched evidence blocks the upgrade.
- A matching explicit native work binding lets Codex resume recover the current next action without a database write. Failure leaves the turn usable and identifies the next check.

Preserve the existing external database and never request a migration just to upgrade the application. Use matching release checksums and the [installation guide](../installation.md). Codex may require a fresh review of changed hooks before enabling automatic delivery. No background service or transcript capture is added.
