# Lodestar v0.6.1

Lodestar v0.6.1 is the release-hygiene patch for the v0.6 trust and recovery
line. It does not change the store format, retrieval semantics, migration
behavior, or recovery contract.

## What changed

- Removed stale release-candidate and publication-pending wording from the
  public documentation.
- Made the supported distribution path explicit: install the checksum- and
  provenance-attested tarball from GitHub Releases. Lodestar is not currently
  published through the npm registry.
- Normalized package `bin` targets so npm publication checks preserve the
  declared metadata without corrections.
- Added `SECURITY.md` with a private vulnerability-reporting route.
- Added Dependabot coverage for npm metadata and GitHub Actions.
- Added conventional `--help` output to the paired retrieval, performance, and
  category benchmark executables.

## Fresh benchmark evidence

The exact patch worktree was measured again on Node.js v22.22.3 under
Linux/WSL:

- The 100-project paired retrieval benchmark preserved 4/4 answers, returned
  zero unrelated-project records, avoided broad search, inspected 90.63% fewer
  files and 97.62% fewer bytes, and was 33.11% faster at the median across 15
  warm samples.
- The full small, standard, and 500-project performance profiles all passed.
  At 500 projects, Lodestar preserved 4/4 answers while inspecting 97.66% fewer
  files and 98.63% fewer bytes, with zero cross-project leakage.
- Across 100 operation samples, p50 latency was 9.537 ms for fresh-store
  startup, 0.048 ms for warm startup, 0.012 ms for exact retrieval, 0.070 ms
  for linked resolution, and 0.509 ms for indexed search.
- Two 25-sample tiny-fixture controls were honest losses on elapsed time:
  Lodestar was 18.82% slower for 8 × 1 KiB documents and 138.46% slower for
  16 × 2 KiB documents. Both still preserved 4/4 answers, avoided broad search,
  returned zero cross-project records, and inspected fewer files and bytes.
  Lodestar is useful when routing and ambiguity matter; it is not a claim that
  every tiny direct lookup becomes faster.
- The 48-trial category plan reproduced deterministically without starting a
  model or incurring cost. It remains a registered live-agent experiment, not
  evidence of model-quality lift until a paid paired run is authorized.

Timing is machine-specific and remains observational. Correctness,
determinism, isolation, broad-search avoidance, and inspected-storage
reductions are the benchmark gates.

## Install

Download `lodestar-agent-context-0.6.1.tgz` and `SHA256SUMS.txt` from the
[v0.6.1 GitHub release](https://github.com/VerbalChainsaw/Lodestar/releases/tag/v0.6.1),
verify the checksum, then install:

```sh
npm install --global ./lodestar-agent-context-0.6.1.tgz
agentctx --version
agentctx doctor --deep
```

## Verification

The local release gate passed 201/201 WSL/Linux tests and 198 native Windows
tests with zero failures and three intentional platform skips.

The published package passed the complete test and packed lifecycle on hosted
Ubuntu, macOS, and Windows runners. The release workflow rebuilt the package
